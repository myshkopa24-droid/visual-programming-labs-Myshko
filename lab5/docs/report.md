# Отчёт по лабораторной работе №5: Чат-боты (Трек C — TypeBot)

## 1. Краткое описание выбранного трека

Для выполнения лабораторной работы был выбран **Трек C (TypeBot)**. В качестве основы использовался готовый шаблон бота для рекомендации фильмов (`Recommendation Movie`), который был полностью адаптирован, переведен на русский язык и расширен кастомной логикой. Бот взаимодействует с внешним API (TMDb), обрабатывает переменные, выполняет динамический поиск и выводит актуальные данные о фильмах и трендах недели.

## 4. Освоенные блоки, ноды и элементы

В ходе выполнения лабораторной работы были изучены и применены следующие элементы TypeBot:

* **Start Event** (начальная точка запуска флоу).


* **Text / Image Blocks** (текстовые сообщения и отправка медиа/постеров).


* **Choice Input** (блоки с вариантами кнопок для интерактивного выбора жанров и действий).


* **Webhook** (настройка GET-запросов к внешнему TMDb API для подгрузки жанров, трендов и деталей фильмов).


* **Set Variable / Variables** (управление переменными, сохранение выбранных пользователем параметров и маппинг списков через `Map item with same index`).


* **Redirect / Jump** (перенаправление на внешние ресурсы, например IMDB, и возврат в главное меню).
