# Отчёт по лабораторной работе №4. n8n

## 1. Краткое описание выполненного

В рамках данной лабораторной работы была освоена low-code платформа автоматизации **n8n**. Были выполнены следующие этапы:

* Выполнена установка и запуск n8n в контейнере Docker с использованием локальных volumes для сохранения данных и конфигурации.


* Созданы базовые и продвинутые workflows, демонстрирующие работу с триггерами, нодами преобразования данных (`Edit Fields / Set`), скриптами на JavaScript (`Code`), логическими ветвлениями (`IF`) и планировщиком (`Schedule Trigger`).


* Настроено взаимодействие n8n с внешним публичным API (`HTTP Request`).


* Развернута база данных **Redis** через Docker и реализована интеграция с n8n для программного создания, чтения, удаления ключей и проверки их существования.


* Оформлена структура репозитория, добавлены экспортированные JSON-файлы workflows и необходимые скриншоты.

Команда для скачивания n8n в gitbush:
docker run -d \
  --name n8n \
  -p 5678:5678 \
  -v n8n_data:/home/node/.n8n \
  -v n8n_storage:/data \
  --restart unless-stopped \
  n8nio/n8n:latest

  Скачалась версия: 2.44.6

## 3. Освоенные ноды

В ходе выполнения лабораторной работы были изучены и применены на практике следующие ноды n8n:

* **Manual Trigger** — запуск выполнения workflow вручную по клику.


* **Schedule Trigger** — автоматический запуск workflow по расписанию (времени).


* **Edit Fields (Set)** — создание и модификация полей данных (`payload`, `topic`, `timestamp`).


* **Code** — написание произвольного пользовательского кода на JavaScript для сложной обработки данных.


* **IF** — организация условных ветвлений потока данных на основе логических выражений.


* **HTTP Request** — выполнение запросов к внешним REST API с парсингом JSON-ответов.


* **Redis** — интеграция с хранилищем данных для управления ключами (запись, чтение, удаление, проверка).

## 5. Выводы своими словами

В результате выполнения лабораторной работы я познакомился с принципами построения low-code решений на базе n8n. Было наглядно продемонстрировано, как визуальное программирование позволяет быстро связывать между собой различные сервисы, базы данных (Redis) и внешние API без написания громоздкого инфраструктурного кода. Особое понимание дала работа с контейнеризацией в Docker, настройка сетевых мостов (`host.docker.internal` / шлюзов) между изолированными контейнерами, а также написание логики на JavaScript внутри ноды Code. Полученные навыки автоматизации и интеграции могут быть эффективно применены в дальнейшей разработке проектных решений.
