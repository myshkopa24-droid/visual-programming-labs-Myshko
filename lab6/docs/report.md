# Отчёт по лабораторной работе №6: Kodular

## 1. Краткое описание базового приложения и ачивок

* **Базовое приложение («Приветствие»):** Разработано мобильное приложение на платформе Kodular. На экране `Screen1` реализован ввод имени пользователя, проверка на заполненность поля с помощью условного блока `if/else`, а также формирование динамического приветствия через блок соединения строк `join`. Для уникализации в интерфейсе добавлена фамилия студента.

## 3. Использованные AI-промпты

При разработке приложения и отладке логики блоков использовались следующие ключевые запросы к ИИ:

1. *«Как в Kodular сделать так, чтобы при нажатии на кнопку проверялось, пустое ли текстовое поле, и выводилось сообщение?»*
2. *«Какие компоненты Kodular нужны для реализации перехода между экранами Screen1 и Screen2 и как правильно передавать управление?»*
3. *«Как настроить компонент Notifier для вывода всплывающих Toast-сообщений после выполнения условия в блоках Kodular?»*
4. *«Как объединить текст из переменной и строку в визуальном редакторе блоков с помощью блока join?»*

---

## 4. Освоенные компоненты и блоки

* **Визуальные компоненты (Designer):** `Screen` (экраны), `Label` (текстовые метки для заголовков, результатов и отображения фамилии), `TextBox` (поле ввода текста), `Button` (кнопки управления), `Notifier` (компонент уведомлений).


* **Логические блоки (Blocks):**
* События клика по кнопке (`when Button.Click do`).
* Условные операторы (`if / else`).
* Проверка свойств элементов (`get TextBox.Text`, установка `Label.Text`).
* Манипуляции со строками (`join`).
* Управление навигацией (`open another screen`).

---

## 5. Ограничения бесплатного тарифа Kodular

В ходе выполнения лабораторной работы были учтены следующие лимиты бесплатного тарифного плана платформы:

* Ограничение на количество проектов (не более 10 активных проектов).
* Ограничение на объём загружаемых медиафайлов и ассетов (до 10 МБ).
* Ограничение на количество используемых внешних расширений (extensions — до 5 штук).
